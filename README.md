# Adam OS — Retro OS Portfolio

A Windows 9x-themed personal portfolio with Pixel Spider mascot, draggable windows, boot sequence, theatrical CV download, and bilingual support (EN + AR with RTL).

## Surface

Open the project in **Antigravity 2.0 (Terminal)** and run the workflow(s) below via slash command.

## Workflows

- `/build-adam-os` — Full build pipeline: plan architecture then build chrome then generate assets then animate motion then write copy then review compliance u can use the assets i already have in the assets folder
- `/generate-assets` — Generate visual assets only
- `/review-build` — Run QA compliance review

## Model

**Gemini Flash 3.6** — all agents use this model.

## Deployment

Static site with **no backend** — deploy for free on **GitHub Pages + Vercel**.

## External Skills (Installed)

| Skill | Used By |
|-------|---------|
| `ui-ux-pro-max` | OS Architect, Chrome Builder, Motion Engineer, QA Reviewer |
| `anti-slop` | Chrome Builder, Copywriter (mandatory), QA Reviewer |
| `pixel-art-sprites` | Pixel Artist |

## Setup

1. Install Antigravity Terminal 2.0.
2. Open this folder in Antigravity Terminal.
3. Ensure the 3 external skills are installed.
4. Run `/build-adam-os` to start the full pipeline.
